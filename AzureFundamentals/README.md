**AZURE FUNDAMENTALS**
It is a foundation-level certification and knowledge area that covers the basic concepts of Microsoft Azure and cloud computing. It is designed for individuals who want to learn about Azure services, pricing, security, and cloud concepts.
Benifits of cloud computing: Scalability, high availability, and elasticity.

***The cloud service models:***
- IaaS(Infrastructure as a Service)- Virtual machines, storage, and networking
- PaaS(Platform as a Service)- Development platforms and tools
- SaaS(Software as a Service)- Ready-to-use software solutions

The cloud deployment models are Public, Private, and Hybrid

***Exploring Relational database in Azure***

The Relational data refers to structured data stored in tables with defined relationships (using primary and foreign keys). In Microsoft Azure, several services support relational data storage, management, and querying.

***Exploring Non-Relational database in Azure***

The Non-Relational databases(also called NoSQL databases) are designed to handle unstructured, semi-structured, and hierarchical data. Unlike relational databases, they do not rely on fixed schemas or table relationships. Azure offers several NoSQL services to store and process non-relational data efficiently.

***Exploring Data Analytics in Azure***

Azure Data Analytics refers to the suite of cloud-based services and tools in Microsoft Azure designed for data ingestion, processing, storage, analysis, and visualization. It enables businesses to gain actionable insights from large and complex datasets.

Azure Services for Data Analytics:
- Azure Synapse Analytics- Combines data lakes and data warehouses into single platform.
- Azure Data Factory- Used to ingest, transform, and move data across systems.
- Azure Databricks- Used for data engineering, data science, and machine learning.
- Azure Machine Learning- A platform for developing and deploying machine learning models.
- Power BI- Creates a Real-time dashboards with Azure Stream Analytics.
