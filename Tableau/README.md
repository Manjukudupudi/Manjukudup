***TABLEAU***

Tableau is a data visualization and business intelligence tool that helps users create interactive and shareable dashboards.
It enables to analyze large datasets and present insights through charts, graphs, and maps.
- Data Visualization- Allows to create dynamic visualizations like bar charts, line graphs, scatter plots, and heat maps.
- Drag-and-Drop Interface- Creating reports by using an intuitive drag-and-drop-interface.
- Data Connectivity- Connects to various data sources, including Excel, SQL Databases, cloud platforms like AWS and Azure, and online services like Google Analytics.
- Interactive Dashboards- Users can filter, drill down, and interact with visualizations directly.
- Sharing and Collaboration- Allows publishing and sharing dashboards through Tableau server, Tableau Online, or exporting them.
